# Smart Mobile Shop Admin Website

Responsive, browser-based management website for a local mobile phone shop. Native mobile app support is future scope; this project currently contains only the website.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`; Vite writes the static site to `dist/`.

Dashboard metrics, charts, orders, repairs, and inventory alerts currently use mock data. Backend integration is planned for a later phase.
